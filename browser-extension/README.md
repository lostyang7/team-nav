# 团队导航助手 - 浏览器插件

这是一个用于快速添加网页到团队导航服务的浏览器插件。

## 功能特性

- 🚀 右键菜单快速添加网页到导航
- 🎯 自动获取页面标题、描述、图标等信息
- ⚙️ 支持自定义导航服务器地址
- 🔧 支持Chrome、Edge等基于Chromium的浏览器

## 安装方法

### 方法一：开发者模式安装（推荐）

1. 下载插件文件到本地
2. 打开Chrome浏览器，进入 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择插件文件夹 `browser-extension`
6. 插件安装完成

### 方法二：打包安装

1. 在 `chrome://extensions/` 页面点击"打包扩展程序"
2. 选择插件文件夹，生成 `.crx` 文件
3. 将 `.crx` 文件拖拽到扩展程序页面安装

## 使用说明

### 1. 设置导航服务器地址

1. 点击浏览器工具栏中的插件图标
2. 在弹出窗口中输入导航服务器地址（例如：`http://localhost:8082`）
3. 点击"保存设置"

### 2. 添加网页到导航

#### 方法一：右键菜单
1. 在任意网页上右键点击
2. 选择"添加到团队导航"
3. 系统会自动打开导航管理页面并填充页面信息

#### 方法二：插件按钮
1. 点击浏览器工具栏中的插件图标
2. 点击"添加当前页面"按钮
3. 系统会自动打开导航管理页面并填充页面信息

### 3. 完善卡片信息

1. 在打开的导航管理页面中，系统会自动填充：
   - 页面标题
   - 页面URL
   - 页面描述
   - 页面图标（如果有）
2. 选择所属分类
3. 根据需要修改或补充其他信息
4. 点击"保存"提交

## 技术实现

### 插件架构

- **manifest.json**: 插件配置文件
- **background.js**: 后台脚本，处理右键菜单和消息传递
- **content.js**: 内容脚本，获取页面详细信息
- **popup.html/js**: 弹出窗口，用于设置和快速操作

### 与导航系统的集成

插件通过以下方式与导航系统集成：

1. **URL参数传递**: 将页面信息通过URL参数传递给导航系统
2. **API接口**: 导航系统提供 `/api/v1/card/auto-fill` 接口接收页面信息
3. **自动填充**: 导航系统的卡片添加页面会自动填充接收到的信息

### 获取的页面信息

插件会自动获取以下页面信息：

- 页面URL
- 页面标题
- 页面描述（meta description）
- 页面关键词（meta keywords）
- 页面作者（meta author）
- 页面图标（favicon）
- 页面主要内容（前200字符）
- 页面语言
- 页面域名

## 注意事项

1. **服务器地址**: 确保设置的导航服务器地址正确且可访问
2. **权限要求**: 插件需要访问网页内容的权限来获取页面信息
3. **跨域限制**: 某些网站可能因为安全策略限制无法获取完整信息
4. **图标文件**: 需要准备16x16、32x32、48x48、128x128像素的PNG图标文件

## 故障排除

### 插件无法安装
- 确保开启了开发者模式
- 检查插件文件夹结构是否正确

### 无法获取页面信息
- 检查目标网站是否允许跨域访问
- 确认页面有完整的meta标签信息

### 无法连接到导航服务器
- 检查服务器地址是否正确
- 确认导航服务正在运行
- 检查网络连接和防火墙设置

## 开发说明

### 修改插件配置

编辑 `manifest.json` 文件：
- 修改插件名称和描述
- 调整权限设置
- 更新图标路径

### 自定义样式

修改 `popup.html` 中的CSS样式来自定义弹出窗口外观。

### 扩展功能

可以在 `background.js` 和 `content.js` 中添加更多功能：
- 批量添加多个页面
- 自定义页面信息获取规则
- 添加更多右键菜单选项
